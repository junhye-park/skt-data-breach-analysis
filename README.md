# SKT 개인정보 유출 사고 원인 분석 및 대응 방안

2025년 발생한 SKT 개인정보 유출 사고의 공격 과정과 원인을 분석하고, 기술적·관리적 대응 방안을 제안한 침해사고 대응 프로젝트입니다.

## 프로젝트 개요

* 수행 형태: 개인 프로젝트
* 관련 교과목: 침해사고대응
* 주요 역할: 공개자료 조사, 공격 타임라인 구성, 원인 분석, 대응체계 평가 및 개선방안 제안
* 분석 기준: 정부 조사자료, 기업 발표자료, NIST Zero Trust, MITRE ATT&CK

## 프로젝트 목적

공개된 사고 조사자료를 바탕으로 공격자의 장기 체류와 대규모 정보 유출이 가능했던 원인을 분석했습니다. 사고를 단순히 요약하는 데 그치지 않고 자산관리, 계정관리, 내부망 접근통제, 핵심 인증정보 보호와 보안 모니터링 관점에서 문제를 구분하고 대응방안을 도출했습니다.

## 주요 분석 내용

### 공격 과정

1. 외부 연결 접점이 있는 시스템 관리망 서버에 악성코드 설치
2. 평문으로 저장된 계정정보를 이용한 내부망 이동
3. 시스템 관리망과 고객 관리망에 추가 공격 거점 확보
4. HSS 관련 서버의 가입자 식별정보와 유심 인증정보 반출

### 주요 원인

* 장기간 패치되지 않은 레거시 시스템
* 서버 계정정보의 평문 저장
* 내부망의 폭넓은 신뢰와 미흡한 접근통제
* 핵심 인증정보 보호 및 키 관리 부족
* C2 통신과 아웃바운드 정보 반출 탐지 한계

### MITRE ATT&CK 관점

| 공격 행위           | ATT&CK 전술           |
| --------------- | ------------------- |
| 악성코드 설치 후 장기 체류 | Persistence         |
| 계정정보 탈취         | Credential Access   |
| 서버 간 이동         | Lateral Movement    |
| 외부 C2 서버와 통신    | Command and Control |
| 가입자 정보 외부 반출    | Exfiltration        |

공개자료만으로 세부 공격기법을 확정하기 어려운 부분은 임의로 Technique ID를 부여하지 않고 전술 수준에서 분석했습니다.

## 제안한 개선방안

* 전사 IT 자산 식별과 패치 관리 생애주기 구축
* EOS 및 EOL 시스템 교체·격리 계획 수립
* 평문 비밀번호 제거와 비밀관리시스템 적용
* 최소권한, 다중인증 및 마이크로 세그멘테이션 적용
* HSM 기반 핵심 암호키 생애주기 관리
* EDR, NDR, SIEM을 연계한 이상행위 분석
* DNS와 대용량 아웃바운드 트래픽 모니터링
* 공격 시나리오 기반 정기 모의훈련 실시

## 프로젝트를 통해 확인한 점

침해사고는 개별 취약점 하나보다 자산관리, 계정관리, 망 구성과 모니터링의 복합적인 실패로 분석해야 한다는 점을 확인했습니다. 또한 대응방안은 보안 솔루션을 나열하는 것보다 확인된 위험과 적용할 통제, 통제의 검증 방법을 연결해야 한다는 점을 학습했습니다.
